Pre-flight

Prerequisites & Domain Decision

Confirm runtime requirements; decide whether to buy a domain.

Runtime requirements

The app needs PHP 8.3+, MySQL 8 (or MariaDB 10.5+), Composer, and daily cron access (for billing:apply-penalties, contracts:send-warnings, contracts:auto-archive). Node is only needed locally for building assets — Hostinger does not need Node installed because public/build/ is uploaded pre-built.

Do you need to buy a domain?

No — you have three options:

OptionCostWhen to use
Free *.hostingersite.com subdomain₱0 (included)Demo / school submission — the recommended pick
Free year-1 bundled domain (annual plan)₱0 first year, ~₱600–900/yr afterIf you want a "real" address like citiescapes.online for the defense
Buy a separate cheap TLD (.xyz, .online, .site)₱100–500/yrOnly if you skipped the bundle and want custom branding

Recommended for the thesis defense: use the free *.hostingersite.com subdomain. You can always switch to a custom domain later without redeploying.

Plan

Choosing a Hostinger Plan

Pick Business annual — Premium does not include SSH and that breaks Laravel deployment.

Why Business plan, not Premium

  • SSH access — required to run composer install, php artisan migrate, and cron debugging
  • 3 GB RAM — Composer needs ~1.5 GB to install the vendor tree
  • 100 GB storage — far more than this app will ever need
  • Free SSL, daily backups, free email accounts (for noreply@ sender)

Premium plan does not include SSH — that turns "deploy a Laravel app" into a 5× harder problem. Pay the small difference for Business.

Phase 01

Local Preparation

Do this on your laptop first so you upload a clean, tested package.

# 1. Make sure tests pass
php artisan test

# 2. Build production assets (Node only needs to exist locally)
npm install
npm run build
# This creates public/build/ — that folder MUST be in your upload / git push

# 3. Optimize composer for production
composer install --no-dev --optimize-autoloader --prefer-dist

# 4. Push to a private GitHub repo (we'll clone from Hostinger)
git push -u origin main
Phase 02

Hostinger Account Setup

  1. Buy Hostinger Business annual plan at hostinger.ph (use student promo if available)
  2. During signup pick "I'll add a domain later" → free *.hostingersite.com subdomain assigned automatically (e.g. citiescapes-xxxx.hostingersite.com)
  3. Pick server region: Singapore (lowest latency from PH)
  4. Access hPanel (Hostinger's cPanel-equivalent)
Phase 03

PHP & MySQL Configuration

Set PHP version

  1. hPanel → Advanced → PHP Configuration
  2. Switch to PHP 8.3 (or 8.4 if available)
  3. Enable these extensions (most are on by default):
bcmath, ctype, curl, dom, fileinfo, gd, intl, json,
mbstring, openssl, pdo_mysql, tokenizer, xml, zip

Create MySQL database

  1. hPanel → Databases → MySQL Databases
  2. Click Create database
  3. Record these three values — required for .env:
    • Database name (e.g. u123456_citiescapes)
    • Username (e.g. u123456_admin)
    • Password (auto-generated — copy immediately, you can't view it again)
  4. The DB host on Hostinger shared is always localhost
Phase 04

Upload the Code (Git Recommended)

Path A — Manual FTP (one-time, slow)

  1. hPanel → Files → File Manager
  2. Navigate to domains/<yoursubdomain>/
  3. Delete the default public_html/ placeholder contents
  4. Upload your zipped project, extract

Path B — Git clone (recommended)

Every future deploy becomes a one-line git pull.

  1. Make sure your repo is pushed to GitHub (private is fine)
  2. hPanel → Advanced → SSH Access → Enable, copy the SSH command
  3. From your local PowerShell: 
    ssh -p 65002 u123456@your-server.hostinger.com
  4. On the server: 
    cd ~/domains/your-subdomain.hostingersite.com
rm -rf public_html
git clone https://github.com/yourusername/citiescapes.git citiescapes
# When prompted for password, use a GitHub Personal Access Token, NOT your password
Phase 05

Webroot Trick — public/ → public_html/

Hostinger expects the webroot to be public_html/, but Laravel's webroot is public/. Two paths.

Option 1 — Symlink (cleanest, but Hostinger sometimes blocks)

cd ~/domains/your-subdomain.hostingersite.com
ln -s citiescapes/public public_html

Option 2 — Move + edit index.php (always works)

cd ~/domains/your-subdomain.hostingersite.com
mv citiescapes/public/* public_html/
mv citiescapes/public/.htaccess public_html/ 2>/dev/null

Then edit public_html/index.php (File Manager or nano). Change the two require lines to point one level up:

require __DIR__.'/../citiescapes/vendor/autoload.php';
$app = require_once __DIR__.'/../citiescapes/bootstrap/app.php';

Why this matters: if you skip this step the browser will show your raw project root including .env — a security risk.

Phase 06

Install & Configure Laravel

Install vendor + environment

cd ~/domains/your-subdomain.hostingersite.com/citiescapes

# 1. Install vendor (no dev packages, optimized)
composer install --no-dev --optimize-autoloader

# 2. Create environment file
cp .env.example .env
nano .env

Edit .env values

APP_NAME=Citiescapes
APP_ENV=production
APP_KEY=                    # will fill in next step
APP_DEBUG=false
APP_URL=https://your-subdomain.hostingersite.com

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=u123456_citiescapes
DB_USERNAME=u123456_admin
DB_PASSWORD=the-password-from-phase-3

MAIL_MAILER=smtp
MAIL_HOST=smtp.hostinger.com
MAIL_PORT=465
MAIL_USERNAME=noreply@your-subdomain.hostingersite.com
MAIL_PASSWORD=that-mailbox-password
MAIL_ENCRYPTION=ssl
MAIL_FROM_ADDRESS=noreply@your-subdomain.hostingersite.com
MAIL_FROM_NAME=Citiescapes

SESSION_DRIVER=database
CACHE_STORE=database
QUEUE_CONNECTION=database

Save with Ctrl+O, Enter, Ctrl+X.

Finish installation

# 3. Generate app key
php artisan key:generate

# 4. Run migrations + seed (creates GM account + 22 rooms)
php artisan migrate --seed --force

# 5. Storage symlink (so uploaded files are publicly served)
php artisan storage:link
# If this fails (shared hosting sometimes blocks symlinks):
#   cd ../public_html && ln -s ../citiescapes/storage/app/public storage

# 6. Cache configs for production speed
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 7. Set folder permissions
chmod -R 775 storage bootstrap/cache
Phase 07

Cron Jobs

A single one-minute cron drives all daily scheduled commands.

hPanel → Advanced → Cron Jobs → Add new cron:

FieldValue
Schedule* * * * * (every minute)
Commandcd ~/domains/your-subdomain.hostingersite.com/citiescapes && /usr/bin/php83 artisan schedule:run >> /dev/null 2>&1

That single line drives every scheduled task — billing:apply-penalties, contracts:send-warnings, contracts:auto-archive, and any others added later. Laravel's scheduler decides internally which ones to run at each tick.

If /usr/bin/php83 isn't the correct path on your server, check hPanel → Advanced → PHP Info for the exact CLI binary path.

Phase 08

Free SSL (HTTPS)

  1. hPanel → Security → SSL
  2. Find your domain → click Install SSL (Let's Encrypt, free, auto-renews every 90 days)
  3. Wait ~5 minutes for propagation
  4. Set APP_URL=https://... in .env, then re-run php artisan config:cache
  5. Open https://your-subdomain.hostingersite.com — green padlock should appear
Phase 09

Smoke Test

Open the deployed site and verify each of these in order:

  1. Public landing renders with both Room Type Cards (Compact / Spacious)
  2. Submit a test inquiry → GM bell increments
  3. Log in as GM (gm@citiescapes.test / password from the seeder)
  4. Create a tenant → temp password email arrives (check Mailtrap or your Hostinger inbox)
  5. Visit /admin/dashboard → occupancy + revenue chart render

If anything returns a 500 error, SSH in and tail the log:

tail -100 storage/logs/laravel.log
Maintenance

Future Deploys

After the first deployment, every update is a five-command SSH session.

ssh -p 65002 u123456@your-server.hostinger.com
cd ~/domains/your-subdomain.hostingersite.com/citiescapes

git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache

Assets: Always build them locally with npm run build and commit the public/build/ directory to your repo. Hostinger shared hosting does not have Node available by default.
