The skipped case is BBT_HTTP_010 (POST without CSRF token returns 419) — Laravel’s VerifyCsrfToken short-circuits via runningUnitTests() so the framework prevents PHPUnit from observing real 419 behaviour; CSRF enforcement itself is unchanged in production and verified by manual browser test.
