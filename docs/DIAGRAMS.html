1. Context Diagram

Citiescapes Apartment Rental Management System and its four external actors. Arrows show data flow, not control flow.

Legend. Boxes are external entities (actors outside the system). The circle is the system as a single process. Arrows show the direction of data flow; the labels next to each arrow name the data exchanged.
Actors:
  1. Public Visitor — anonymous browser user. Reads the public landing page; submits inquiries via the contact form. Cannot log in.
  2. Tenant — authenticated tenant user (role = 'tenant'). Accesses the tenant portal: dashboard, contract, bills, requests, profile.
  3. General Manager (GM) — authenticated admin (role = 'gm'). Operates every administrative function: rooms, tenants, billing, contracts, archive, audit log, communications, settings.
  4. Scheduler / Cron — automated system actor. Runs three nightly jobs: billing:apply-penalties, contracts:send-warnings, contracts:auto-archive.

2. Diagram 0 — Top-Level Process Decomposition

Decomposes the system into its seven subsystems (SS1 – SS7) and the seven core data stores they share. Each numbered process corresponds to one Livewire module group in app/Livewire/.

Legend. Circles = processes (one per subsystem); double-line bars = data stores; rectangles = external entities. Solid arrows = synchronous user-driven flows; dashed marigold arrows = scheduler-driven flows. The dashed grey line shows that every process writes to audit_logs (drawn from process 6 only to avoid visual clutter).
Process catalog.
  1. 1.0 Room Operations — public listings, GM room CRUD, inquiries, occupancy dashboard, public room-type cards. Reads/writes D1 (rooms), reads D2 (users) for tenant linkage.
  2. 2.0 Tenant Management — tenant account creation, first-login activation flow, self-profile, manual + auto archive. Reads/writes D2 (users).
  3. 3.0 Billing & Collections — initial & monthly billing, penalty escalation cron, payment confirmation, deposit-to-arrears credit, eviction shortcut. Reads/writes D3 (bills + payments), reads D4 (contracts).
  4. 4.0 Contract & Lease Management — drafts, two-step tenant acknowledgement, scan upload + access control, renewals, terminations, expiry warning + auto-archive crons. Reads/writes D4 (contracts), updates D1 (rooms) on activate/terminate.
  5. 5.0 Reports & Archive — passive receiver of snapshots from SS1/SS2/SS3/SS4; provides browse, filter, CSV/PDF export, restore (tenant_account only), permanent delete. Reads/writes D5 (archives).
  6. 6.0 Authentication & Access Control — login, lockout, OTP, password change, role enforcement, system settings, audit log viewer. Reads D2 (users), writes D6 (audit_logs) on every privileged action.
  7. 7.0 Communications & Notifications — tenant requests, complaints, announcements, in-app bell, email fan-out. Reads/writes D7 (notifications + announcements), reads D2 (users) to resolve recipients.
